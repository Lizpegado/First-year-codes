#First-Year C Codes
A growing collection of C programs written during my first year as a cse student .This repository tracks my progress as I build core problem solving and programming fundamentals.

##Topics covered
* Basic and operators: Input/output formatting, arithmetic operators, and unit conversions
* conditional statements:'if else logic, number classification and leap year checks
* loops and number manipulation:Digit extraction, counting,reversal,multiplication tables.
* upcoming:arrays, strings,functions,recursion and pointers.

#How to run any program
.compile the file using GCC in the terminal;
'''bash
gcc filename.c -o output
'''
.run the compiled executable:
'''bash
./output
'''
